Write your post in **Markdown**.

## How this works

1. Copy this file and rename it (e.g. `my-first-post.md`).
2. The filename becomes the URL: `/writing/my-first-post`.
3. Files starting with `_` (like this template) are ignored.
4. Set `draft: true` to hide a post in production (still visible in `npm run dev`).

### Markdown you can use

- **Bold**, *italic*, `inline code`
- [Links](https://example.com)
- Lists, quotes, and headings

```ts
// fenced code blocks work too
const hello = "world";
```
